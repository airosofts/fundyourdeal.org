# Fund Your Deal — SEO page plan (from competitor study, 2026-10-19)

Competitors studied: Kiavi (618 URLs), Lima One (574), RCN (1,815, mostly blog), Visio, CoreVest, LendingOne (220), Easy Street (575), New Silver (1,023 — strongest), Roc (74), Griffin (864), Defy (299), Rehab Financial (230), Civic (161), Baselane (721, closest marketplace analog), BiggerPockets, OfferMarket (10,905 — showed up for 7 of 12 queries). Raw URL lists: `competitor-sitemaps/`.

## What ranks
| Query | Page type on page 1 |
|---|---|
| dscr loan | Product page with full explainer |
| dscr loan requirements | Guides |
| dscr loan calculator | Working calculators only |
| fix and flip loans | Guides + product pages |
| hard money loans | Publishers/definitions (Wikipedia, Rocket, Chase) → target "hard money lenders [state]" |
| bridge loan real estate | Guides, consumer + investor intent mixed → say "investment property" plainly |
| brrrr loan | Guides on the two-loan structure |
| short term rental loan | Lender product pages + STR guides ("airbnb loan" is ambiguous) |
| portfolio loan for rental properties | Guides |
| ground up construction loan investor | Product pages |
| dscr loan texas / fix and flip loans florida | **State pages only — even thin ones rank. Biggest opening.** |

Competitor weaknesses to beat: thin state pages (Kiavi TX ~500 words with a Kansas disclaimer; Easy Street TX generic), contradictory figures across pages (New Silver 15% vs 20% down; Visio 80% vs 85% LTV), calculators without FAQs or with email-gated PDFs, empty FAQs (OfferMarket).

## Rules for every money page
- **One dataset.** Every figure comes from `loan-terms-2026-10.md`, with an "as of" date, so pages never contradict each other.
- **Standard blocks:** quick answer · typical terms · worked example with real arithmetic · comparison table · calculator link · 6–10 FAQs (FAQPage schema) · how matching works plus a "not a lender" disclosure.
